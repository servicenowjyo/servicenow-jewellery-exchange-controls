# Measure before claiming time savings
Use a consented anonymized batch and the same correctness criteria for both workflows. Record analyst start/finish for bill lookup, policy calculation, repeat check, item inspection, approval and posting separately. Measure 3+ comparable batches manually and with import/triage; report median, p95, errors and human minutes. Include data preparation and review; exclude training only if labelled. Goal under 5 minutes refers to automated triage after import, not final exchange settlement. Local `engine_ms` is a single warm-process algorithm timing, not a business benchmark. No Emmadi baseline was observed.
